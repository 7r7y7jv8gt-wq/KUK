# Hitachi 135 — interiørkamera

[Last ned hele modden, versjon **1.1.0.1**](https://github.com/7r7y7jv8gt-wq/KUK/releases/download/hitachi135-interior-camera-v1.1.0.1-20261030/KK25_Hitachi_135_KRISTENSEN_EDIT.zip). Filnavnet **KK25_Hitachi_135_KRISTENSEN_EDIT.zip** beholdes. Dette er bygget fra de fire delene brukeren lastet opp.

Interiørkameraet sto omtrent **5,4 meter fra førerens setereferanse**, med skrå retning, under det gamle skjulte interiøret. Det er flyttet til den aktive førerplassen, i anslått øyehøyde **0,725 m over** førerfiguren og **0,10 m foran** den. Kameraet peker fremover med **5° helning nedover**, følger den nye seterammen og overvognas rotasjon, og ligger over sete-/nakkestøttegeometrien. Synsfeltet er fortsatt **60°**, og nærklipp er **0,05 m**.

Musekontroll, speil, kamerabytte og utvendig kamera beholder innstillingene. Kameraets opprinnelige node-ID beholdes. En tom transform beholder plassen der kameraet sto, slik at alle andre nodebaner forblir identiske. Alle opprinnelige meshdata, shape-filer, animasjoner, teksturer, lys, navn, logoer, fysikk og andre kjøretøyinnstillinger er bevart.

Bare hoved-I3D-en, kameraets XML-kobling og versjonsnummeret er endret. Én README er lagt til: **97 originalfiler → 98 filer totalt**. Den selvstendige kontrollen sammenligner alle opprinnelige noder, attributter, nodebaner og filhashverdier. ZIP-integritet og hver pakket fil er kontrollert mot kandidaten. Pakken ligger på GitHub Releases som én ZIP fordi den er større enn 100 MiB.

Avslutt FS25, erstatt moddens ZIP med denne filen, behold filnavnet og start på nytt. **Ingen test inne i FS25 er utført.** Øyehøyden er satt ut fra førerfiguren og setegeometrien; den er ikke kontrollert visuelt i spillet.

Se [kamerakontroll](CameraValidation.json), [uavhengig sammenligning](IndependentValidation.json), [geometrigrunnlag](SeatGeometryBounds.json) og [pakkevalidering](validation.json).
