# Semi Lowloader 3A — horizontal K&K Maskin side logos

Full mod: [`FS25_semiLowloader3A.zip`](../FS25_semiLowloader3A.zip), version **1.0.0.4**.

Both side logos now use the owner's selected `KKMaskin_logo_horizontal_diffuse.dds` from the supplied prefab. The DDS is copied byte for byte, preserving the original lettering, artwork, transparency and mipmaps. The missing OneDrive reference now points to the bundled texture.

The existing decal plane is 1 m × 0.5 m. Each original centre, width and rotation is retained; vertical scale is adjusted to display the selected horizontal artwork at 4:1. Both surfaces face outward with upright, unmirrored UV mapping.

The six three-way Viking lamps and all trailer controls retain the completed lighting setup. The vehicle XML and shape binary are byte-identical to version 1.0.0.3. All local I3D texture resources now resolve.

The owner requested a different graphic or text on the long rear mudflap; that replacement is pending their choice. The existing mudflap is retained in this side-logo build.
