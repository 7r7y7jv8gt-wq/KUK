# Fast Coupler – FS25-konvertering

[Last ned FS25_fastCoupler_by_bragstadmodding.zip](https://raw.githubusercontent.com/7r7y7jv8gt-wq/KUK/main/FS25_fastCoupler_by_bragstadmodding.zip)

Legg ZIP-en direkte i mods og aktiver den i lagringen. Ikke pakk den ut.
Finnes under Vekter, med grunnpris 550 og 17 opprinnelige farge-/overflatevalg.
Musestyring velges i butikken. Utgangene bruker fastCoupler og fastCoupler_NEW,
som i originalen, og trenger redskaper med tilsvarende inngangskobling.

Konvertert fra den opplastede FS22_fastCoupler_by_bragstadmodding.zip.
Forfatteropplysninger og logoer er bevart. FS25-materialer, fargekonfigurasjoner,
modellformat v10, materialspor og kollisjonsfiltre er tilpasset.
Alle 4410 modellflater, festepunkter og kollisjonsdata er bevart.
XML er validert mot de offisielle FS25-skjemaene. Ikke kjørt inne i FS25.

SHA256: `f44737cae9ce27bfa8360bad8bb341740b59aeb477c2a3c0159d91c9bd5b64d3`
