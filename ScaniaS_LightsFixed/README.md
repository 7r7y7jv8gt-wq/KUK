# Scania S Tridem — lights and texture repair

[Download FS25_ScaniaS_Tridem.zip](../FS25_ScaniaS_Tridem.zip?raw=true)

Replace the original FS25_ScaniaS_Tridem.zip in your mods folder with this file. Keep the ZIP filename unchanged to preserve the mod name used by saved games.

- Removed the stock roof lamps spawning behind the added Briods and obsolete light references.
- Enabled white light-controlled glow on all seven Briod DRL strips.
- Repaired local textures and enabled orange lenses on all 66 side diodes.
- Corrected stale beacon mappings and removed conflicting hidden red diode controls.
- Kept mesh binaries and texture images intact. Missing black and dark-glass maps now use matching bundled alternatives.

XML, local assets, light nodes, archive CRC, and scene-path preservation were checked. Live rendering and gameplay still need testing in FS25 / GIANTS Editor. Base-game assets require an FS25 installation.
