Shed.i3d — Farming Simulator 25 / GIANTS Editor 10

Open Shed.i3d in GIANTS Editor with the FS25 game installation configured.
The original UVs, normals, object positions, and separate roof/wall materials are preserved.

Textures reference the existing FS25 game assets:
$data/maps/mapUS/textures/woodPlanksDecal_diffuse.dds
$data/maps/mapUS/textures/concrete_diffuse.dds

The uploaded OBJ and MTL contain no texture image data. DDS images are not bundled; the model requires these assets from your FS25 installation.

This is a model asset, not a complete placeable mod. No gameplay XML or collision setup was added.
XML structure and mesh indices were checked; GIANTS Editor runtime testing was not available.
