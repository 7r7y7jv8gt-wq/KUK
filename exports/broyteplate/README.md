Last ned broyteplate_GIANTS.zip, pakk ut begge filene i samme mappe, og åpne broyteplate.i3d i GIANTS Editor 10 med Farming Simulator 25 satt opp.

Tellefsdal-brøyteplata med begge toppstag og festepunkt er skilt ut. Original plassering og skala er beholdt. Logoen er utelatt fordi tellefsdal.dds mangler. Cylinder_normal.dds og Cylinder_specular.dds er erstattet med spillets standardteksturer.

Shapes-filen er originalfilen og inneholder også ubrukt traktorgeometri; bare brøyteplata vises i denne i3D-scenen. XML og referanser er kontrollert. Modellen er ikke testet i GIANTS Editor. Dette er en modell for import, ikke en komplett spillmod.
