# Complete Volvo L90 mod

Includes the full original model, geometry, textures, sounds and bucket, the added FOR9T/OZZ/Optibeam lighting, and the automatic L90H transmission. Version 1.0.0.3.

## Download all five files

Keep the original filenames and put all five in the same folder:

1. [FS25_volvoL90.z01](./FS25_volvoL90.z01?raw=true)
2. [FS25_volvoL90.z02](./FS25_volvoL90.z02?raw=true)
3. [FS25_volvoL90.z03](./FS25_volvoL90.z03?raw=true)
4. [FS25_volvoL90.z04](./FS25_volvoL90.z04?raw=true)
5. [FS25_volvoL90.zip](./FS25_volvoL90.zip?raw=true)

## Install

1. Open FS25_volvoL90.zip with **7-Zip**. All four .z0x files must be beside it.
2. Extract into a folder named **FS25_volvoL90**. This folder must contain modDesc.xml directly, alongside scripts, shared and vehicles.
3. Remove the previous Volvo mod ZIP/folder from your mods directory, then put the extracted FS25_volvoL90 folder there.
4. Restart FS25 and select the mod when loading your save.

**Do not put the five split archive files directly in mods.** For multiplayer, create a normal single ZIP from the extracted folder's contents, with modDesc.xml at the ZIP root, and install that ZIP instead of the extracted folder.

All 50 extracted files were checked against the complete rebuild using 7-Zip. XML and local model references checked. Not tested in FS25.
